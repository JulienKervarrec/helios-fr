# 2. Synchronisation légère

Helios combine une source de consensus et une source d’exécution. Il synchronise rapidement les données nécessaires au client sans conserver une base complète.

Le checkpoint de subjectivité faible sert de point de départ : il doit correspondre à une racine Beacon Chain crédible et suffisamment récente.
