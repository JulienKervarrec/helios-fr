# 4. Ethereum, OP Stack et Linea

La CLI propose des parcours distincts pour Ethereum, les réseaux OP Stack et Linea. Le réseau sélectionné détermine les endpoints, le consensus attendu et les paramètres de validation.

Base apparaît comme réseau OP Stack supporté. Cette composition montre comment un même client peut réutiliser un cœur de vérification avec des règles de réseau adaptées.
