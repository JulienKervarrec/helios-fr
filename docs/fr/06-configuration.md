# 6. Configuration et bibliothèque

Les options de la CLI peuvent être regroupées par réseau dans un fichier de configuration. Port RPC, endpoint consensus, endpoint exécution, checkpoint et fallback sont ainsi explicités.

Les dossiers core, ethereum, cli et examples montrent aussi l’utilisation comme bibliothèque Rust. La séparation rend possible une intégration dans un portefeuille ou une application WebAssembly.
