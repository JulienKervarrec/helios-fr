# 5. Checkpoints et subjectivité faible

Un checkpoint est une racine de bloc de consensus, non un hash de bloc d’exécution. Il constitue la racine de confiance initiale du client.

Le dépôt prévoit un checkpoint fourni par l’utilisateur, un cache du dernier finalisé et des solutions de repli. Une valeur malveillante ou trop ancienne peut orienter la synchronisation vers une chaîne incorrecte.
