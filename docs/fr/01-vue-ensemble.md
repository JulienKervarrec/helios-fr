# 1. Vue d’ensemble

Helios est un client léger multichaîne écrit en Rust. Il transforme un RPC d’exécution non fiable en RPC local vérifiable, avec une empreinte réduite et une cible WebAssembly.

Le dépôt sépare le cœur, les réseaux Ethereum, OP Stack et Linea, la CLI et les exemples.
